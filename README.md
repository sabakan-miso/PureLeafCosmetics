# PureLeafCosmetics

## 概要
自然の恵みを肌へ届ける、架空のスキンケアブランド「PureLeafCosmetics」のランディングページを制作しました。

## コンセプト
**肌に、洗練されたケアのひと時を。**

自然由来の成分を大切にしながら、毎日無理なく使い続けられるスキンケアを提案するブランドをイメージしました。

植物の自然な美しさと上質感を組み合わせ、安心感と信頼感が伝わるデザインを目指しています。

## 制作のポイント
- 植物やスキンケア商品の写真を使用し、自然の恵みを表現
- 落ち着いた色合いと余白を活かした、上品で見やすいレイアウト
- 商品の魅力やブランドのこだわりが伝わる構成
- スマートフォンでの閲覧にも配慮したレスポンシブデザイン
- スクロールに合わせたアニメーションによる、自然な視線誘導

## 使用技術
- HTML
- CSS
- JavaScript
- Vite
